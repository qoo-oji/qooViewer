# qooViewer

macOS向けの漫画ビューアアプリです。フォルダ、zip/cbz、rar/cbr、7z/cb7、PDF、EPUB(固定レイアウトの画像ベースのコミックEPUBのみ)、および画像ファイルそのものに対応しています。
cooViewer (https://github.com/coo-ona/cooViewer) を参考に、その操作性・機能を元に作られています。 素晴らしいアプリを公開してくださった作者の coo-ona 氏に感謝します。

## ⚠️ 初回起動時の注意(開発者公証について)

qooViewerはApple Developer Programに加入して行う開発者公証(notarization)を受けていません。
そのため、ビルドした `qooViewer.app` をダウンロードやAirDrop、他のMacへのコピーなどで受け取って
(Xcodeで自分でビルドしてそのまま `Cmd + R` で実行する場合はこの問題は起きません)初めて開こうと
すると、macOSのGatekeeperにブロックされて、ダブルクリックだけでは起動できません。

その場合は、以下の手順で一度だけmacOSに起動を許可してください(一度許可すれば、以降は通常通り
ダブルクリックで起動できます)。

1. `qooViewer.app` をダブルクリックして起動を試みます。
   「"qooViewer.app"は壊れているため開けません」、または「Appleにより悪質なソフトウェアが
   ないか確認できないため、"qooViewer.app"を開けません」といった内容のダイアログが表示されます。
   このダイアログには「完了」(または「ゴミ箱に入れる」)しか選択肢がありませんが、
   **「ゴミ箱に入れる」は選ばず**、「完了」を押してそのまま閉じてください。
2. Appleメニュー(画面左上の) →「システム設定」を開きます。
3. 左側の一覧から「プライバシーとセキュリティ」を選択します。
4. 右側のペインを一番下までスクロールすると、「セキュリティ」欄に
   「"qooViewer.app"は開発元を確認できないため使用がブロックされました」といった内容の
   メッセージと、その横に「このまま開く」ボタンが表示されています。これをクリックします。
5. 確認のダイアログが表示されるので、再度「このまま開く」を選択します
   (Macのログインパスワードや Touch ID での認証を求められる場合があります)。
6. これでアプリが起動します。以降この手順は不要で、通常通りダブルクリックで起動できます。

**補足**: Apple Developer Program(有償)に加入し、開発者証明書での署名・公証を行えば、
この手順自体が不要になります。上記はあくまで公証なしでビルド済みアプリを実行する場合の手順です。

macOS 15 (Sequoia) 以降

## できること

- フォルダ / zip・cbz / rar・cbr / 7z・cb7 / PDF / EPUB(固定レイアウトの画像ベースのコミックEPUBのみ)に対応
- 対応する画像フォーマット: JPEG(jpg/jpeg) / PNG / GIF / BMP / WebP / HEIC / TIFF(tif/tiff) / AVIF
- 画像ファイルをそのまま開く(Finderで複数選択した画像はまとめて1冊として開く。ファイル名順)。この場合はアプリ側の記録(読書位置・レイアウト・ブックマーク・お気に入り・メタデータ・履歴)を一切残さない
- EPUB / PDF / CBZ 形式で書き出す機能(ブックマーク・ページレイアウト設定・メタデータのいずれかを
  持つ本が対象。元のファイル形式はフォルダ / zip・cbz / rar・cbr / 7z・cb7 / PDF / EPUB のすべて)。
  CBZには ComicInfo.xml を同梱し、Komga・Kavita・YACReader などからも読める
- 表示中のページを画像ファイルとして書き出す「画像のエクスポート」(見開きを1枚に結合しての
  書き出しにも対応。元の画像をそのまま複製するので画質は劣化しない)
- 見開き表示 / 単ページ表示の切り替え、横長画像の自動単ページ化
- 右開き(日本式) / 左開き(欧米式)の切り替え。EPUB/PDFが読み方向・見開き/単ページを指定している
  場合(EPUBはページごとの見開き内配置も)、その本を初めて開いたときに指定を読み取り、ページ
  レイアウト設定として取り込む。以降の表示は取り込んだ内容に従い、読み方向・見開き・ページごとの
  レイアウトはEPUB/PDFでも他の形式と同じように自由に変更できる(取り込みは本ごとに1回だけなので、
  変更した内容が次に開いたときファイル側の値へ戻ることはない)
- 表示モード切り替え(画面内に収める / 横幅に合わせる / 横幅に合わせる(単ページ) / 拡大縮小しない。
  f キーで循環、⌘1〜⌘4 で直接選択)
- トラックパッドのピンチ拡大(どの表示モードでも使え、カーソル位置を中心に無段階で拡大。拡大中は
  画面表示用より高解像度の画像へ自動的に切り替わる。2本指ダブルタップで200%と等倍を切り替え)
- コントラスト補正(紙の黄ばみでコントラストが甘くなった古いスキャンを、白黒がきっちり出るよう
  補正して表示。本ごとにON/OFFを記憶し、カラーページは自動的に判定して対象外にする)
- キーボード・マウスホイール・画面クリック・マウスジェスチャー(ボタンを押したままなぞる)でのページ送り
  (キー/マウスの割り当ては環境設定でカスタマイズ可能、1つの操作に複数のキー/トリガーを割り当て可能。
  スクロールできる表示モードだけの上書き設定も持てる)
- マウスにだけ割り当てられる「タブを閉じる」「ウインドウを閉じる」「qooViewerを終了」(既定では未割り当て)
- トラックパッドの「ページ間をスワイプ」フリック操作に対応。2本指スクロールで画像が動く向きを
  反転する設定もある
- 画面下部のプログレスバーでのページ移動、ホバーでのサムネイルプレビュー
- フルスクリーン表示中はツールバー/プログレスバーを自動的に隠し、カーソルを近づけると半透明で再表示
  (ウインドウ表示中でも、ツールバー・プログレスバー・サイドパネルを同じように隠せる)
- ページ一覧(サムネイルグリッド)画面(サムネイルの大きさ・間隔・余白のほか、サムネイル下の表示
  〈ページ番号/ファイル名/なし〉・文字サイズ・表示中ページの枠の色・マウスホイール1ノッチあたりの
  スクロール行数を調整可能)
- サイドパネル(「ブラウザ」「ブックマーク」「履歴」「ページ」「リソース」の5モード。フォルダをたどって
  本を開く、今開いている本の中身をたどる、お気に入り・ブックマーク・履歴・ページの一覧、リソース消費の
  確認。フォルダの一覧は名前・サイズ・種類・作成日・変更日を基準に昇順/降順で並べ替え可能)
- サイドパネル・ページ一覧の右クリックメニュー(本の行からは「開く」「新規ノーマルウインドウ」
  「新規シークレットウインドウ」「新規タブ」で開き方を選択、お気に入り・ブックマークの行からはその場で
  名前の変更・削除、ページのサムネイルからはブックマークの付け外し、「Finderで開く」。書庫・PDFの中の
  ページは入れ物のファイルを表示し、代わりに「画像をエクスポート」で1枚だけ取り出せる)
- 外観のカスタマイズ(ビューアの背景色に加えて、ページ一覧パネル・ツールバー・プログレスバー・
  サイドパネル・ウェルカム画面・その他のパネル〈「情報を見る」パネル・操作のフィードバック・
  拡大率の表示〉の6つの面それぞれについて、背景色・「すりガラス」の濃さ・文字とアイコンの輪郭
  〈文字の影〉を個別に設定可能)
- ブックマーク機能(追加・一覧・名前変更・削除・次/前のブックマークへジャンプ・一括リネーム。
  EPUBの目次・PDFのアウトライン・ComicInfo.xmlのしおりは、その本を初めて開いたときに自動で取り込む)
- お気に入り機能(本をフォルダ階層で整理して登録・管理。メニューバー/ツールバー/右クリックメニュー/
  キーボードショートカットから登録、ホバーでサブフォルダが展開する一覧、専用の編集ウインドウで
  フォルダ作成・リネーム・削除・ドラッグ&ドロップ移動)
- ページレイアウト機能(本ごと・ページごとに読み方向、見開き/単ページ表示、ページ順序、
  ページの除外を指定可能。メニューバー「Edit」のレイアウトのグループ・右クリックメニュー・ツールバーの
  自動レイアウトボタンから操作でき、変更の適用範囲(このページだけ/これ以降/本全体など)を選べる)
- メタデータ機能(本ごとに著者・タイトル・シリーズ・巻数を登録。ツールバーの表示とEPUB/PDF/CBZの
  書き出しに使われる。未登録の本にはファイル名から推測した値があらかじめ入り、推測の規則
  〈ファイル名フォーマット・巻数フォーマット・除外文字列〉も編集できる。EPUB/PDF/ComicInfo.xmlを
  持つ本からは初回に自動で取り込む)
- 「ブックマーク・レイアウトの編集」ウインドウ(本を開いていなくても、すべての本のブックマーク・
  ページレイアウト設定を横断的に一覧・検索・絞り込み・編集。ページの並べ替え・除外、サムネイル
  プレビューにも対応)
- お気に入り・ブックマーク・ページレイアウト設定・メタデータをJSONファイルとして書き出し/読み込みできる
  ライブラリデータのインポート・エクスポート機能
- 保存データの整理(qooViewerが保存データを持つ本を一覧し、元のファイルが見つからないものだけに
  絞り込んで、本単位で削除できる。ファイル自体には触れない)
- リソースモニタ(サイドパネルの「リソース」モード。qooViewer自身のCPU・メモリ・ディスクの読み書きを
  時間軸のグラフで確認できるほか、開いている本のページ画像・サムネイルのキャッシュが設定の上限に対して
  どれだけ使われているか、先読みが追いついているか、ディスクに何がどれだけ残っているか、設定と実際が
  食い違っていないかを表示する。計測は手動でON/OFFし、起動時は常にOFF)
- キャッシュの設定(メモリに残しておくページ画像の上限〈100〜2000MB、既定300MB、本1冊あたり〉、
  前後に先読みするページ数、ページのサムネイルをディスクに保存する機能〈既定OFF〉のON/OFF・上限・
  使用量の確認・即時削除)
- ウェルカム画面に「最近開いたファイル」「最近お気に入りに追加したファイル」を各最大10件表示
  (それぞれ個別にON/OFF可能)
- スライドショー(自動ページめくり)
- 実寸表示ウインドウ(見開きの左右いずれかのページを原寸大の別ウインドウで表示)
- 拡大鏡(マウスカーソル位置を中心に画像の一部を円形に拡大表示。拡大率とレンズの直径を調整可能)
- 「情報を見る」(表示中のページの種類・サイズ・場所・作成日/変更日・解像度・色空間などを、
  Finderの「情報を見る」のようなパネルでウインドウ内に表示)
- 同じフォルダ内の前/次の本への移動(既定は名前順。サイドパネルのフォルダブラウザで選んだ並べ替えに
  合わせる設定も選べる)
- 複数ウインドウ・複数タブ対応(Dockアイコンの右クリックからも新規ウインドウを開ける)。同じ本を同じ
  種類のウインドウ・タブで二重に開くことはなく、既に開いている場合はそのウインドウが手前に出る
- シークレットウインドウ(開いた本の情報を一切残さない)。すべての経路で既定をシークレットにする
  「シークレットモードで起動」設定も選べる
- 「最近開いたファイル」の履歴の消去(メニューバー・サイドパネル・環境設定のいずれからでも)
- 本ごとの続きから再開(表示モード・読み方向・スクロール位置を自動保存)
- zip/cbz 内ファイル名の文字コード自動判定(古い日本語zipの文字化け対策)
- 表示言語の切り替え(日本語 / English / システムに従う)

## ビルド方法

### 前提

- macOS 15 (Sequoia) 以降
- Xcode 26 以降(無料、App Store からインストール)。最新版を推奨します。
  - Swift 6.2 の「既定のアクター分離を MainActor にする」設定を使っているため、これより古い
    Xcode ではビルドできません。
- 初回起動時にXcodeの追加コンポーネントのインストールを求められたら許可してください。

### 手順

```sh
git clone https://github.com/qoo-oji/qooViewer.git
cd qooViewer
open qooViewer.xcodeproj
```

あとは Xcode で `Cmd + R` を押すだけです。依存ライブラリは Swift Package Manager が自動的に
取得します(バージョンは `Package.resolved` に固定してあるので、誰がいつ clone しても同じ
組み合わせでビルドされます)。初回だけ、C/C++で書かれたライブラリ(unrar)をソースから
ビルドするため時間がかかります。

コマンドラインからビルドすることもできます。

```sh
xcodebuild -project qooViewer.xcodeproj -scheme qooViewer -configuration Debug build
```

アプリアイコン、Finderからの関連付け(zip/cbz等のダブルクリック、フォルダや画像のDockへのドロップ)、
日本語/Englishの翻訳データは、すべてリポジトリに含まれています。Xcode 側で追加の設定をする必要は
ありません。

### 署名について

このリポジトリには Apple Developer の Team ID を **含めていません**。特定の開発者のアカウントに
結び付いた値をコミットしてしまうと、clone した人が「そのTeamのアカウントが無い」というエラーで
ビルドできなくなるためです。Team を設定しないままでも、Xcode は「Sign to Run Locally」
(ローカル実行用のアドホック署名)でビルドし、自分のMac上で実行できます。

自分の開発者アカウントで署名したい場合は、`Configurations/Local.xcconfig` というファイルを
新しく作り、次の1行だけを書いてください(`ABCDE12345` の部分はご自身の Team ID)。

```
DEVELOPMENT_TEAM = ABCDE12345
```

このファイルは `.gitignore` 済みなので、リポジトリには入りません。Xcode の
「Signing & Capabilities」で Team を選ぶ方法でも署名はできますが、そちらは `project.pbxproj` に
直接書き込まれるため、うっかりコミットして Team ID を公開してしまう事故が起きます。

### サンドボックスによる制限について

qooViewerはサンドボックス下で動作するため、ユーザーがパネルやドラッグ&ドロップで直接選んだ
ファイル/フォルダにしかアクセス権がありません。「同じフォルダ内の次の本」機能、およびFileメニューの
「同じフォルダのファイルを開く」機能は、まだアクセス許可のない兄弟ファイルを読もうとするため、
**ファイル単体(zip/cbz等)を直接開いた場合**は一覧が空になります(フォルダを開いた場合は、
その配下がまとめて許可されるため問題ありません)。

この場合は、環境設定(Cmd + ,)の「フォルダのアクセス権」画面から「フォルダを追加…」で、漫画ファイルを
置いているフォルダ(ホームフォルダや外部ボリューム、ドライブのルートフォルダなど、どこでも
指定できます)へのアクセスをあらかじめまとめて許可しておくと、以後そのフォルダ配下では
「同じフォルダのファイルを開く」「前の本/次の本」が常に正しく機能します。
(Fileメニュー→「同じフォルダのファイルを開く」→「このフォルダへのアクセスを許可…」からも、
今開いている本のフォルダだけをその場で許可できます。どちらも一度許可すれば、次回起動後も
有効です(セキュリティスコープ付きブックマークとして保存されるため)。環境設定の
「フォルダのアクセス権」画面では、許可済みフォルダの一覧確認・取り消しもできます)

なお「最近開いたファイルを開く」機能は、開いた時点でセキュリティスコープ付きブックマークとして
アクセス許可を保存しておくため、サンドボックス下でも次回起動後に問題なく開けます。

### 表示言語について

qooViewerは日本語とEnglishを切り替えられます(環境設定の「一般」画面→「表示言語」)。翻訳データは
`qooViewer/Resources/Localizable.xcstrings`(String Catalog)としてリポジトリに含まれており、
macOS本体の言語設定とは独立して切り替えられます。

**注意**: エラーメッセージ(ファイルが開けなかった場合など、ごく一部の文言)は、アプリ内の表示言語
設定ではなく、Macのシステム言語設定に従って表示されます。これは実装上の意図的な簡略化です。

### rar のファイル名について

Unicodeのファイル名を持つrar/cbr(現在作られているものはほぼこれに該当します。RAR5、および
Unicode名を併記したRAR4)は、日本語のファイル名でも正しく読み取れます。

一方、Unicode名を一切持たない極めて古いRAR4(ファイル名をShift-JISのバイト列だけで持っているもの)は
文字化けします。`Unrar.swift` が内部で使っているRARLAB提供のunrarライブラリが、アーカイブを読んだ
時点で既にそのバイト列をシステムのロケール(macOSではUTF-8)として解釈してしまい、qooViewer側からは
元の生のバイト列に手が届かないためです。ライブラリの外側では対処できません。

zip/cbz のファイル名の文字コードは、qooViewer 側で自動判定しているため、この問題は起きません
(rarだけがライブラリの内部でファイル名を文字列化しており、qooViewer から生のバイト列に触れない
ためこうなっています)。判定は書庫単位でまとめて行い、Shift_JIS(CP932)・EUC-JP・CP949(韓国語)・
GBK/Big5(中国語)や、UTF-8 の目印が付いていない書庫を読み分けます。1つの書庫の中に複数の文字
コードが混在している場合(UTF-8 との混在を除く)は、そのうちの1つに揃えて読むため、片方は
文字化けしたままになります。
