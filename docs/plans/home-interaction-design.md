# ホームの操作の統一 ―― 設計(2026-09-27)

ホームの 4 つの面(本棚のコレクション一覧・コレクションの中・スマートライブラリ・ファイルブラウザ)で、クリック・選択・キー・
右クリック・ドロップの約束がばらばらになっている。これを 1 つの考え方から組み直す案。きっかけは監査
([macos-conventions-audit-2026-09-26.md](macos-conventions-audit-2026-09-26.md))の末尾の「ホームの中で操作の形が 2 通り」と #28〜#30・#36・#39。

**2026-09-27 に §2 のとおり実装した(テストは通過。実機での操作の確認はまだ)。** §1 は実装前の現状で、コードを読んで洗い出したもの
(3 本の並行調査の報告。行番号は調査時点)。実装で §2 と違えたところは §5。
§2 以降は 2026-09-27 に利用者と決めた内容。**編集モードは残す**(利用者の判断: 無くすとドロップでコレクションを作る・足す手段が不便になる)。

---

## 1. 現状

### 1.1 面ごとの操作

| 観点 | 本棚: 一覧 / 中 | スマートライブラリ | ファイルブラウザ | サイドパネル(参考) |
|---|---|---|---|---|
| クリック | 開く(一覧はタイルの**絵だけ**。名前は押しても何も起きない)。編集モードでは選択のトグル | 選ぶ | 選ぶ | 開く(設定で 2 回) |
| 開く | 1 回のクリック | ダブルクリック・Return・⌘↓ | ダブルクリック・Return・⌘↓ | クリック |
| ⌘ / ⇧ クリック・余白のクリック | 読まない | 足す・範囲・外す | 足す・範囲・外す | ― |
| 帯(マーキー) | 編集モードの中だけ(足す向き) | **無い** | あり(AppKit) | ― |
| キー(矢印・⌘A・type-select) | **無い** | あり | あり(アイコン表示の ⇧矢印は範囲にならない) | ― |
| 出る(上の階層へ) | 見出しの ‹ だけ。キーは無い | ⌘↑・Esc(‹ が cancelAction) | ⌘↑・⌘[ | ― |
| 右クリック | 一覧は**編集モードの中だけ**。中は常に出るが「コレクションから削除」は編集モードだけ | 常に | 常に | 常に |
| 右クリックの対象の枠 | 無い | 無い | AppKit の標準 | 自前の枠 |
| 名前の変更 | シート(右クリック・ホームメニュー。中では編集モードの見出しのクリック) | ― | その場で(選んだ項目の名前をもう一度クリック) | ― |
| 取り除く | ゴミ箱のボタン(編集モード)・右クリック。確認あり、取り消し無し | ― | ⌘⌫(取り消せる)・⌥⌘⌫(確認) | ― |
| ⌘C | 中だけ。**編集モードの選択が要る** | 選んだ本 | 選んだ項目 | ― |

**編集モードの働き**は、docs/14 の「3 つだけ」より多く、15 個あった(調査の一覧。§4 で全部の行き先を決める)。

### 1.2 ドロップ

受け口はウインドウ全体に 1 つ。ホームのほうの受け口(`welcomeDropHandler`)がドロップを引き受けるのは「本棚・編集モード・シークレットでない」の
3 つがそろったときだけ。それ以外はすべて「開く」に回る。タイルそのものにも受け口は無い。

**落としたものの種類**の分け方は `ShelfFolderResolver.role` の 1 つだけ(開く側もコレクション側も同じものを使っている):

| 種類 | 何か |
|---|---|
| 本 | 書庫・PDF・EPUB。画像フォルダ(直下に画像がある)。章フォルダ(本のファイルが無く、画像を直接持つ子フォルダがある) |
| 棚 | 直下に本が並ぶフォルダ |
| ばらの画像 | 画像ファイル 1 枚以上 |
| 本でないもの | 中間フォルダ(子が棚だけ)・空のフォルダ・対応しないファイル・パッケージ |

| 種類 | 「開く」に回ったとき | 本棚(編集モード) / 本を追加パネル | ファイルブラウザ「コピー・移動」 |
|---|---|---|---|
| 本 | 開く | 一覧: 1 つのコレクションを作る(名前を訊く)/ 中・パネル: 追加 | ファイルとして運ぶ |
| 棚 | 並びの先頭の本を開く | 一覧: フォルダ名のコレクションを作る / 中・パネル: 中の本を展開して追加 | 同上 |
| ばらの画像 | その場限りの 1 冊(何も記録しない) | **黙って無視** | 同上 |
| 中間フォルダ | 最大 8 段下りて最初の本を開く | **黙って無視** | 同上 |
| 空・対応しないファイル | 読み込みに失敗してエラー。**表示中の本も閉じてホームに戻る** | **黙って無視** | 同上 |
| 複数(全部が画像のときを除く) | **先頭の 1 件だけ開き、残りは黙って捨てる** | 種類ごとに振り分け、本でないものは黙って捨てる | 全部運ぶ |

ほかの食い違い:

- ファイルブラウザで「開く」の設定のとき、フォルダの行の上に落とすと、その行が強調されるのに、実際には開く。
- ウインドウ全体の受け口は何を落としても枠を強調する(開けないものでも)。
- スマートライブラリの左の「対象フォルダ」欄はフォルダだけを受け、足せなければビープを鳴らす。ファイルブラウザの「コレクションを作成」は
  本が無いと知らせる。**本棚だけが黙る。**
- 設定「Finder から開いたとき」(置き換える/タブ/ウインドウ)は Dock と Finder の経路にだけ効き、ウインドウへのドロップには効かない。

## 2. 変えること

### 2.1 ホームの全部の面で揃えること(本棚の一覧・コレクションの中・スマートライブラリ・ファイルブラウザ)

| 操作 | 変えた後 | 今と違う所 |
|---|---|---|
| クリック | 1 つ選ぶ | 本棚は今「開く」(編集モードでは選択のトグル) |
| ダブルクリック・Return・⌘↓ | 開く(コレクション・束・フォルダは中へ、本は読む) | 本棚は今 1 回のクリックで開き、キーは無い |
| ⌘ / ⇧ クリック・余白のクリック | 足す/外す・範囲・全部外す | 本棚は今これが無い |
| 帯(ドラッグで囲んで選ぶ) | 余白から、いつでも | 本棚は今編集モードの中だけ。スマートライブラリは今無い |
| ⌘A・矢印・Home/End/Page・頭文字で選ぶ | どの面でも同じ | 本棚は今無い。ファイルブラウザのアイコン表示は ⇧矢印が範囲にならない |
| ⌘↑・Esc | コレクションの中・束の中から出る | 本棚は今見出しの ‹ だけ |
| 右クリックの対象 | 対象に枠を描く(サイドパネルと同じ) | 今はどの面も描かない |
| 設定「クリック 1 回で開く」 | 新設。本棚の 2 面とスマートライブラリに効く(ファイルブラウザには効かない)。既定 OFF。ON ならクリックで開き、選ぶのは ⌘ / ⇧ クリック・帯・キー | ― |

本棚は、スマートライブラリの選択・キーの部品(`SmartGridSelection`・`GridKeyboardNavigation`・`PanelListScrollTracker`)に載せ替える。
セルの高さを揃える約束も引き継ぐ。

### 2.2 本棚で変えること(編集モードの外)

| 何 | 変えた後 | 今 |
|---|---|---|
| タイルの名前の部分 | 絵と同じ 1 つの枠(押せば選ぶ) | 押しても何も起きない |
| 一覧のタイルの右クリック | いつでも出る: 開く・本を追加…・別のライブラリへ移動・名前を変更… | 編集モードの中だけ |
| ⌘C(コレクションの中) | 選んだ本をいつでもコピー | 編集モードで選んだ本だけ |

### 2.3 編集モード(残す)

| 何 | 変えた後 | 今 |
|---|---|---|
| 役目 | **コレクションに入れる・外す操作を前に出すモード** | クリックとドロップの意味を切り替えるモード |
| クリック | 外と同じ(選ぶ) | 選択のトグル |
| ドロップ | 入れる(§2.4) | 同じ(ただしタイルの上は下のとおり変わる) |
| 全選択・ゴミ箱のボタン、右クリックの「削除…」「コレクションから削除」 | **今のまま**(編集モードの中だけ) | ― |
| 見出しのコレクション名を押して名前の変更、丸い選択の印、ホームメニューの「編集モード」、画面を移ると抜ける | 今のまま | ― |
| 入ったとき・出たときの選択 | 外で選んでいたものを持ったまま入る/出る。画面を移ったら捨てる(今どおり) | 入るまで選べない。出ると捨てる |

### 2.4 ドロップ

| 落とす場所 | 変えた後 | 今 |
|---|---|---|
| 本棚(編集モードの外)・スマートライブラリ・ビューア | 開く | 同じ |
| 本棚の一覧(編集モード)・タイル以外 | 新しいコレクションを作る | 同じ |
| 本棚の一覧(編集モード)・**タイルの上** | **そのコレクションへ追加**(タイルを強調) | 新しいコレクションになる |
| コレクションの中(編集モード) | そのコレクションへ追加 | 同じ |
| ファイルブラウザ | 今の設定(開く / コピー・移動)のまま。**「開く」の設定のときはフォルダの行を強調しない** | 「開く」なのにフォルダの行が強調され、開く |

本棚には「開く / 入れる」の設定を作らない(編集モードが切り替える)。

「開く」の直し:

| 落としたもの | 変えた後 | 今 |
|---|---|---|
| 複数の本 | 先頭を開き、落とした本の並びを「次の本・前の本」でたどる(コレクション・スマートライブラリから開いたときと同じ `BookSequence`。自然順、棚は中の本に展開) | 先頭だけ開き、残りは黙って捨てる |
| 本でないもの(空のフォルダ・対応しないファイル) | 受け取らない(ウインドウの枠を強調しない)。複数の中に混ざっていれば、件数と理由を知らせる | 受け取ってエラーになり、表示中の本まで閉じる |

「入れる」の直し: 本が 1 つも入らなかった・一部を入れなかったときに、件数と理由を知らせる(今は編集モードへのドロップも「本を追加」パネルも黙る)。
ばらの画像・中間フォルダを入れないのは今どおり。

### 2.5 別件(この設計とは独立に直す)

- 棚をドロップしてコレクションを作っても、そのフォルダの許可が `FolderAccessStore` に入らず、自動登録フォルダが「アクセスを許可」待ちになる
  (docs/14 と食い違う。**報告のまま。直す前に読み直す**)。
- 名前入力のシートで、棚のフォルダ名が既存のコレクション名と同じだと、理由を出さずに「作成」だけが押せない。

### 2.6 変えないこと

編集モードの存在と、削除まわりが編集モードの中だけであること。ファイルブラウザのドロップの設定。サイドパネル。ビューアへのドロップ。
コレクション・ライブラリの名前の変更がシートであること。

## 3. 進め方

1. §2.1〜2.3(クリック・選択・キー・右クリック・編集モードの役目の変更)。
2. §2.4(ドロップ)。
3. §2.5 と、スマートライブラリの帯・アイコン表示の ⇧矢印。

各段階で MANUAL・docs/14・docs/15 を直す。CHANGELOG は指示があったとき。

## 4. 経緯

編集モードを無くす案を一度出したが取り下げた(利用者は了承していなかった。無くすと、ドロップを「開く」にしている人がドロップで
コレクションを作る・足す手段を失う)。その穴を埋めようとした「本棚の開く/入れるの設定」「ライブラリのチップやコレクション名への
ドロップ」「ドラッグ中だけ出る『新しいコレクション』の枠」も、編集モードを残すので要らなくなり、すべて取り下げた。

## 5. 実装で決めたこと・違えたこと(2026-09-27)

- **「開けないものは受け取らない(ウインドウの縁を強調しない)」は、落とした後の判定にした。** ウインドウ全体の受け口は SwiftUI の
  `onDrop` で、ドラッグ中には URL を読めない(読めるのは落とした後)。落とした後に下調べし(`DroppedBooks`)、開けなければ開かずに
  知らせる。表示中の本は閉じない ―― 実害だった部分はこれで無くなる。
- 「開く」の下調べは、ドロップだけでなく同じ入口を通る「開く…」パネル・ファイルブラウザの複数を開く操作にも効く(`AppState.open(urls:)`)。
  Dock・Finder から複数を渡されたとき・「新規ウインドウで開く…」で複数を選んだときも並びを作る。Dock・Finder からの「開く」は
  種類ごとに何回かに分かれて届くので、まとめ直してから開く(docs/04「BookOpenRequest」。実機の検証で、本を渡しての起動でウインドウが
  2 枚残る・タイトルが変わらなくなるのを見つけて直した)。
- 本棚の選択は、本を開いて戻ったときは残す(スマートライブラリと同じ。同じ画面へ戻るので、見えていないものを消す心配は無い)。
- コレクションの一覧・中は、画面に出たときにキーの行き先になる(入った直後・戻った直後から矢印キーが効く)。
- 右クリックの相手の枠と、編集モードでファイルを落とす先の札の強調は同じ枠(どちらも「これが相手」の印)。
- 本を追加パネルの知らせ(本でない・既に入っていた)は、パネルの下の欄に出す(シートの上に浮かべる知らせの場所が無い)。
