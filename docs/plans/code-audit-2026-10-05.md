# 致命的な不具合とリソースの過大消費 ―― コード監査(2026-10-05)

[ui-state-consistency-audit-2026-10-04.md](ui-state-consistency-audit-2026-10-04.md)(画面と状態の食い違い)の直し(1.81 の後の 23 コミット、
`7f454f5..f900cd7`)を対象に、**リソースリーク・クラッシュ・ハングアップ・ファイル破損・ファイル消失**に繋がりうる所と、**メモリ・ディスクの
過大な消費**を探した監査。範囲を 7 つ(ファイル操作 / 本を開く入口・窓 / ビューア・ブックマーク / 保存データ・付け替え・許可 / 書き出し・表紙 /
ホーム・メタデータ・環境設定 / サイドパネル)に分け、担当ごとに差分と呼び先を読み、候補ごとに反証を試みてから残した。主な指摘は別に
コードを辿り直して確かめた。範囲の外(1.81 以前からのコード)で目に付いたものも §3 に挙げ、同じ段で直した。

結論: **クラッシュ・利用者のファイルの消失や破損に当たるものは見つからなかった**。中 5・中〜低 3・低 15、範囲外 8。

凡例: 判定は **確認**(経路を全部辿った)/ **見込み**(UI フレームワークの振る舞い・時機に依存)。ID は担当の番号(A1 = ファイル操作 …
A7 = サイドパネル)。

## 4. 棄却したもの(抜粋)

次の本の飛ばしの無限ループ(上限 50・並びは消費・兄弟は折り返さない)、continuation の二重再開(`FileIO.withDeadline`・`WindowSheet`)、書き出しの

(大文字小文字・データ側の頭は畳む)、Matcher の NFC・`/private`、データの削除経路(一時的な失敗を「無い」と読む所は無い)、選択の絞り込みの計算量
(どれも O(n))、ブックマーク・レイアウトの知らせのループ、`DataUndoStack` の大きさ(50 段・値の写し)。
