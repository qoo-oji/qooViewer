# macOS の標準との違いの監査(2026-09-26)

UI の作法が macOS の標準(HIG と、Finder・Safari・Preview・TextEdit の実際の振る舞い)と違う箇所の総点検の記録。
きっかけは、ファイルメニューの「閉じる」(⌘W)が、赤い閉じるボタンの差し替えに巻き込まれてタブをすべて閉じていたこと
(下の「この日に直したもの」)。メニューバー / ウインドウ・タブ・ダイアログ・環境設定 / ウインドウの中の操作、の 3 つに
分けてコードとコメント・docs を読んだ。

- **この表はコードを読んだ結果で、実機では確かめていない。** ✔ は、報告のあと手元でコードを読み直して事実を確かめたもの。
- 「意図」は、コードのコメントか docs に理由(ユーザーの判断・過去の不具合・プラットフォームの制約)が書いてあるもの。
  「理由なし」は見つからなかったもの ―― うっかり外れた可能性が高いが、直す前に経緯を確かめること。
- 実害・危険があるもの(1〜5)は同じ日に直した。残りは直すかどうかをまだ決めていない。直したら、その行を「直したもの」へ移す。
